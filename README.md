# 많이 타는 정류장을 잇는 저상버스, 정류장까지만 가는 해피콜

청주시 해피콜(특별교통수단) 1년 운행기록으로 검증한 교통약자 Hub 연계 이동지원 분석입니다.
「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 분석보고서의 그림 1~10과 본문 수치를 그대로 재현하는 코드를 담고 있습니다.

## 핵심 결과

| 지표 | 값 |
|---|---|
| 외곽 12개 읍면 운행 비중 (건수 / 차량점유 / 주행거리) | 14.8% / 17.8% / 26.8% |
| 1건 이동거리 (외곽 / 시내) | 13.9km / 5.1km |
| 평균 대기 (특장차 / 일반차량) | 20.1분 / 14.5분 |
| Hub 연계 시 대상 운행 1건 차량점유 | 37.1분 → 15.9분 (−57%) |
| 연간 절감 차량시간 (제안 노선, 전환율 50%) | 5,319시간 (특장차 1,498 / 일반차량 3,821) |
| 특장차 평균 대기 (실측 재생 시뮬레이션) | 21.1분 → 19.8분 (−6%) |
| 연간 탄소 감축 (전환율 50%) | 39.5t CO2e |

## 실행 방법 (Visual Studio Code)

1. **Python 3.10 이상**과 VS Code의 Python 확장을 설치합니다.
2. 이 폴더를 VS Code로 엽니다 (파일 → 폴더 열기).
3. 터미널(Ctrl+`)에서 가상환경을 만들고 패키지를 설치합니다.
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1      # Windows PowerShell  (macOS·Linux: source .venv/bin/activate)
   pip install -r requirements.txt
   ```
4. 데이터는 `data/교통분석_데이터.zip`에 들어 있어 따로 준비할 필요가 없습니다 (압축은 코드가 알아서 풉니다).
5. 실행합니다.
   - **그림 하나씩**: `analysis/` 폴더의 그림 파일(예: `fig05_hub_occupancy.py`)을 열고 오른쪽 위 ▷ (Run Python File). 그림이 창으로 뜨고 `figures/`에 저장됩니다. 터미널에서는 `python analysis/fig05_hub_occupancy.py`
   - **한꺼번에**: `python run_all.py` → 그림 10장 + `outputs/report_numbers.csv`
   - **파일 하나로**: `python report_figures_final.py` (같은 결과, VS Code에서 `# %%` 셀을 위에서부터 하나씩 실행 가능)

처음 실행할 때 공통 데이터를 준비해 `data/_cache/`에 저장하므로 30초 안팎 걸리고, 그다음부터는 그림 하나에 몇 초면 됩니다(그림 7 시뮬레이션은 약 20초). 각 그림 파일은 앞 그림을 먼저 돌리지 않아도 혼자 실행됩니다.

그림 글꼴은 설치된 한글 폰트(Windows는 맑은 고딕)를 쓰므로 보고서 그림과 글자 모양만 조금 다를 수 있고, 수치와 그래프는 같습니다. 이 저장소의 `figures/`는 Noto Sans CJK로 만든 보고서 수록본입니다.

해피콜 CSV를 원자료부터 다시 만들려면 `data/`에 정보공개청구 zip을 넣고 `python prepare_happycall.py`를 먼저 실행합니다.

## 그림과 코드

| 보고서 그림 | 사용 데이터 | 방법 |
|---|---|---|
| 1 고령화율 vs 종합병원 거리 | 연령별 인구, 정류장 승하차(06~09시), 종합병원 7곳 | 동 고령인구를 정류장 오전 승차 비율로 배분, 최근접 종합병원 거리(직선×1.3) 가중평균과 상관분석 |
| 2 외곽 운행 비중 | 해피콜 운행기록 | 외곽(12개 읍면 출발·도착) vs 시내(동↔동) 건수·점유시간·주행거리 비중 |
| 3 외곽 출발 도착 지도 | 해피콜, 행정동 경계, Hub·종합병원 좌표 | 외곽→시내 17,910건의 도착 동별 건수 |
| 4 저상노선 후보 7개 | 정류장 좌표·이용량, 보고서 노선표 | 노선 순서대로 정류장 연결 (설계 규칙 코드 포함) |
| 5 Hub 연계 차량점유 | 해피콜, 읍면 Hub 거리 | 운행 1건마다 탑승시간 × (Hub 거리 ÷ 실제 이동거리) 반사실 계산 |
| 6 동시 운행 특장차 | 해피콜 특장차 배차·하차 시각 | 1분 단위로 운행 구간을 쌓은 평일 시간대별 평균 |
| 7 실측 재생 시뮬레이션 | 특장차 일반 호출 174,731건 | 실제 호출 순서대로 재배차, 실측 대기 20.1분에 맞춰 차량 수 보정 |
| 8 외곽 목적지 상위 12 | 해피콜 | 도착 동 순위, 핵심 목적지 동 구분 |
| 9 1건 이동거리 분포 | 해피콜 | 외곽·시내 이동거리 히스토그램 |
| 10 차종별 대기·취소율 | 해피콜 | 일반 호출 대기, 전체 호출 시간대별 취소율 |

## 분석 기준

- 차종 (청주시 회신): 2025년 G1 특장차·G2 임차택시 / 2026년 G1·G2 특장차 / G3 바우처택시 / G5 자가용승용차
- 완료 운행: 배차결과 `고객하차` 중 소요시간 이상치 제외 383,964건
- 외곽 12개 읍면: 고령자의 종합병원 평균 거리 5km 초과 읍면 (오창·내수·옥산·남이·강내·미원·남일·북이·문의·가덕·현도·낭성)
- 종합병원 거리는 오송 베스티안병원(화상 전문)을 포함한 값이며, 제외하면 상관계수는 0.64
