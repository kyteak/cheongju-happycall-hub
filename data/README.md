# data 폴더

분석에 쓴 데이터는 이 폴더의 `교통분석_데이터.zip`(약 32MB)에 들어 있습니다. 저장소를 내려받으면 따로 준비할 것이 없습니다.

## 1. 그림·수치 재현에 필요한 것 (`analysis/fig01~fig10`, `run_all.py`)

스크립트가 처음 실행될 때 `교통분석_데이터.zip`을 `data/교통분석_데이터/`로 자동으로 풉니다 (압축을 직접 풀어 두어도 됩니다).
그림·수치 재현에 쓰는 파일은 다음과 같고, zip에는 이 밖에 정류소·노선·복지시설·대규모점포·탄소계수 등 보조 자료도 들어 있습니다.

| 파일 | 용도 |
|---|---|
| `cheongju_happycall_2025-10_2026-10.csv` | 해피콜 운행기록 (정리본, 443,608건) |
| `cheongju_grid_100m.geojson` | 행정동 경계 43개 + 100m 격자 |
| `청주_정류장_월별_시간대별_승하차_.csv` | 정류장 좌표·승하차 (cp949) |
| `청주_거점병원_의료접근성_분석.xlsx` | 종합병원 좌표 (`청주_의료기관`, `종합병원_기준점` 시트) |
| `2026년 8월 연령별(만) 인구현황.xlsx` | 행정동 연령별 인구 |

## 2. 해피콜 CSV를 원자료부터 다시 만들 때 (`prepare_happycall.py`)

`data/cheongju_happycall_2025-10_2026-10.csv` 가 만들어집니다.
